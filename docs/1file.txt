## 🎯 O QUE É O LUMIKIDS

App PWA de histórias infantis com IA.
- **Domínio:** lumikids.app
- **Tagline:** "Histórias que iluminam o coração das crianças"
- **Público:** Crianças 2–10 anos + pais cristãos + escolas
- **Plataforma:** PWA instalável (iOS + Android + Desktop)
- **Idioma padrão:** Português Brasil (pt-BR)

---

## 🛠️ STACK OBRIGATÓRIA

- **Framework:** Next.js 14 com App Router + TypeScript
- **Estilo:** Tailwind CSS + variáveis CSS customizadas
- **Animações:** Framer Motion
- **Estado global:** Zustand
- **Backend:** Firebase (Auth + Firestore + Storage + Functions)
- **IA Geração:** Google Gemini 1.5 Flash (GRATUITO)
- **IA Narração:** Google Cloud Text-to-Speech (1M chars/mês grátis)
- **Pagamentos:** Stripe (5 planos de assinatura)
- **Fonte:** Nunito (Google Fonts) — peso 400, 600, 700, 800, 900
- **Ícones:** Lucide React + FontAwesome 6

> ⚠️ NÃO usar OpenAI em nenhum momento.
> TODA geração de texto usa Gemini 1.5 Flash.
> TODA narração de voz usa Google Cloud TTS.
> Ambos integram nativamente com Firebase (mesmo ecossistema Google).
